# Cape Control website

The public pages of Cape Control, served by GitHub Pages at https://and-games-studio.github.io/capecontrol/

- `index.html`: home page.
- `privacy/`: privacy policy (linked from the Play Store listing, AdMob's consent message and the game's Settings).
- `terms/`: terms of service.
- `delete/`: how to delete the data the game keeps (the Play Console data safety form links it).

Plain HTML and CSS, no build step, in the game's comic ink. The fonts are the game's, Bangers and Barlow (SIL Open Font License 1.1, in `fonts/` with their licenses), served from here, so the site makes no requests to other servers.

The privacy policy, the terms and the deletion page describe what the Android build does: AdMob's rewarded videos (the Zappo break between shifts) and the optional Google Play Games copy of the career. When the build changes, they change with it.
